#### Featured Projects

**[senior-care-rag-agent](https://github.com/praneetreddy3/senior-care-rag-agent)** — Agentic RAG assistant answering Medicare/Medicaid/PACE eligibility questions from real CMS and state program PDFs, with a query → retrieve → grade → generate → verify pipeline so every answer is grounded and cited. 54-question eval: Hit@4 0.926, MRR 0.861, grounded rate 0.981, faithfulness 0.778 (independently LLM-judged). LangGraph, FAISS/ChromaDB; served via FastAPI, Streamlit, and an MCP server.

**[Bridges-NBI-Analysis](https://github.com/praneetreddy3/Bridges-NBI-Analysis)** — PySpark ETL + ML pipeline over 950K+ National Bridge Inventory records. Engineered 26 features from 15 source items, handled a 9:1 class imbalance, and tuned an XGBoost model from 0.75 to 0.93 ROC-AUC; results persisted to MongoDB with automated Databricks SQL reporting.

**[Healthcare-Financial-Analysis](https://github.com/praneetreddy3/Healthcare-Financial-Analysis)** — Multi-tool ETL pipeline (Python, MySQL, R) over 4,233 CMS Hospital Cost Report records, quantifying the charity-care vs. net-income tradeoff across U.S. hospitals.
